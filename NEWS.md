# safeAI 0.1.0

- Added the first stable implementation of the univariate SAFE rank graduation metrics.
- Added the tie-aware `rgx()` engine.
- Added the lowercase public functions `rga()`, `rgr()`, `rge_star()`, and `rge()`.
- Added support for continuous, binary, logical, and ordered-factor outcomes.
- Added Lorenz, dual Lorenz, concordance, and combined curve helpers.
- Kept robustness-scenario construction outside the package so `rgr()` can evaluate predictions generated by any user-defined perturbation or stress procedure.
- Added tests, help pages, a vignette, citation information, and continuous-integration configuration.
